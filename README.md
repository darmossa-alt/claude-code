# Custom CSS — Thème PrestaShop

Feuille de styles personnalisée pour la boutique PrestaShop [ottopuntouno.fr](https://ottopuntouno.fr).

## Sections

| Section | Description |
|---------|-------------|
| 1. Header & Global | Couleurs, logos, curseur, barre de navigation |
| 2. Fond de page & Carrousel | Image de fond, positionnement du carrousel |
| 3. Bannière personnalisée | Bannière photo en haut de page d'accueil |
| 4. Sections produits | Grille produits, fiches miniatures, centrage |
| 5. Pages produits & internes | Mise en page des pages internes |

## Utilisation

Copier le contenu de `custom.css` dans le module CSS personnalisé de PrestaShop :
**Back-office → Apparence → Thème & Logo → CSS personnalisé**
